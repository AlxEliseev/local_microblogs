# Local Microblogs

---
## Описание
Это pet - проект для отработки работы с FastAPI, SQLAlchemy, pydantic, pytest.
Представляет из себя корпоративный сервис микроблогов.

<img src="/imgs/twitter_clone.png">

## Реализованый функционал

В проекте реализован функционал:

 - Лента твитов
 - Добавление/удаление твита
 - Вставка картинки в твит
 - Пользователь может подписаться на пользователя и отписаться от него
 - Пользователь может отметить твит как понравившийся


## Технологии
Проект запускается в трёх Docker - контейнерах:
 - Фронтенд на базе Nginx сервера
 - База данных PostgreSQL
 - Бэкенд проекта выполнен на языке Python c использованием фреймворка FastApi на сервере Uvicorn

## Установка и запуск
Для установки на сервере выполните команду
```
git clone https://github.com/AlxEliseev/local_microblogs.git
```

Для запуска сервиса на сервере перейдите в директорию *skillbox_advanced_diploma*
```
cd local_microblogs
```
и выполните команды
```
docker compose build
docker compose up
``` 

Для заполнения базы данных тестовыми данными после запуска сервера запустите скрипт *seed_demo_data.py*
```
docker exec -it twitter_clone_app python -m app.seed_demo_data
```
